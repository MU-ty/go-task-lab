学习路线 · 4 个章节
01

请求从哪里来？

net/http · 路由 · Handler

＋
从 cmd/web/main.go 开始，找到 http.Server。再看 internal/web/handler.go，理解 GET 和 POST 怎样进入不同的函数。试一试：在浏览器开发者工具的 Network 面板观察一次新增请求。
02

数据怎样传递？

struct · JSON · 指针

＋
页面用 fetch 发送 JSON，Go 用 json.Decoder 写入结构体。*bool 帮助区分“未传字段”和 false。试一试：新增一个优先级字段，让前后端都能读写它。
03

任务怎样存下来？

interface · slice · 文件读写

＋
Service 通过 Repository 接口操作 JSONFile。业务层只关心接口，网页和命令行共用同一份逻辑。试一试：刷新网页，再查看本地 tasks.json，追踪一次完整的数据流。
04

同时操作会怎样？

goroutine · Mutex · httptest

＋
Go 同时处理多个 HTTP 请求。sync.Mutex 保护完整的读取、修改和保存，避免同一服务内丢失更新。试一试：阅读并发新增测试，再运行 go test ./...。
